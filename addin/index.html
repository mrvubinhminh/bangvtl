✏️ Bảng Vẽ Toán cho Word & PowerPoint

Vẽ hình học phẳng, hình không gian, công thức → chèn vào tài liệu; hình mang dữ liệu để chọn và sửa tiếp. Tác giả: Vũ Tiến Lực.

Bước 2 · Cài vào Office

Word / PowerPoint trên web (Office 365 — dễ nhất)
  1. Mở một tài liệu Word (hoặc bài PowerPoint) tại office.com.
  2. Thẻ Trang đầu → Phần bổ trợ (Add-ins) → Phần bổ trợ khác / Nâng cao → mục Phần bổ trợ của tôi → Tải lên phần bổ trợ của tôi (Upload My Add-in).
  3. Chọn file manifest.xml vừa tải → Tải lên. Nút Bảng vẽ Toán hiện ở thẻ Trang đầu.
  4. Cài 1 lần trong Word là dùng được cả PowerPoint trên web (cùng tài khoản).
Word / PowerPoint trên Windows (Office 365, 2019, 2021, 2024)
  1. Tạo thư mục, ví dụ C:\BangVeToan, chép manifest.xml vào.
  2. Chuột phải thư mục → Properties → Sharing → Share… → chọn chính mình → Share. Ghi lại đường dẫn mạng, dạng \\TEN-MAY\BangVeToan.
  3. Mở Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs → dán đường dẫn mạng vào Catalog Url → Add catalog → tick Show in Menu → OK. Đóng hẳn Word rồi mở lại.
  4. Insert → My Add-ins (Phần bổ trợ của tôi) → SHARED FOLDER (THƯ MỤC DÙNG CHUNG) → chọn Bảng Vẽ Toán → Add. Làm tương tự trong PowerPoint.
Word / PowerPoint trên macOS
  1. Finder → Go → Go to Folder… → dán ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (chưa có thư mục wef thì tạo) → chép manifest.xml vào.
  2. PowerPoint: làm tương tự với ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef.
  3. Mở lại Word / PowerPoint → Insert → Add-ins → My Add-ins (mũi tên nhỏ) → chọn Bảng Vẽ Toán.
Cài cho cả trường / tổ (Microsoft 365 quản trị)

Quản trị viên vào admin.microsoft.com → Settings → Integrated apps → Upload custom apps → chọn manifest.xml → giao cho các giáo viên. Add-in tự hiện trong Word / PowerPoint của mọi người.

Dùng thế nào?

  1. Thẻ Trang đầu → Bảng vẽ Toán → khung bên phải mở ra → ✏️ Vẽ hình mới.
  2. Cửa sổ bảng vẽ lớn: bút, hình phẳng, hình không gian, nét đứt, thước, compa, chữ & công thức (phím T)… → ✓ Chèn vào tài liệu (Ctrl+Enter).
  3. Muốn sửa: bấm chọn hình trong tài liệu → ✎ Sửa hình đang chọn → vẽ tiếp → ✓ Cập nhật. Dữ liệu nét vẽ nằm ngay trong file .docx / .pptx.

Cần Office 2019 trở lên hoặc Microsoft 365 / Office trên web. Office 2010, 2013, 2016 bản cũ không chạy add-in loại này. PowerPoint chèn hình dạng vector (SVG); Word chèn ảnh PNG nét cao.
